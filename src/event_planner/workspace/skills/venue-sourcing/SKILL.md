# Venue Sourcing

## Overview

Turning a brief into a defensible venue shortlist. The failure mode this guards
against is a shortlist that looks great on paper and falls apart two weeks out,
usually because of a constraint nobody asked about.

## When to Use

Shortlisting venues, comparing two finalists, or sanity-checking a venue the
client has already picked.

## Instructions

### 1. Capacity is not the number on the listing

Listed capacity is almost always standing-room. Apply the format:

| Format             | Usable fraction of listed capacity |
| ------------------ | ---------------------------------- |
| Standing reception | 1.0                                |
| Theatre seating    | ~0.7                               |
| Seated dinner      | ~0.5                               |
| Classroom / banquet with AV | ~0.4                      |

A 120-capacity loft seats about 60 for dinner. Book for the format, not the
headline number, and add 10% headroom for late RSVPs.

### 2. Price the day, not the rate

The day rate is rarely the cost. Before comparing two venues, get all of:

- **Load-in / load-out window.** Charged separately at many venues. A freight-
  elevator-only building can add hours of labour on both ends.
- **Overtime.** Ask the hourly rate past the included window and when it starts.
- **Required labour.** Union venues mandate their own crew. This is not optional
  and is not in the day rate.
- **Approved-vendor lists.** If catering is restricted to an approved list, the
  venue effectively sets the catering floor too.
- **Surcharges.** Seasonal heating/cooling, weekend premiums, holiday rates.
- **Insurance.** Certificate of insurance requirements and minimum coverage.

Two venues cannot be compared on day rate alone. Compare all-in.

### 3. Constraints that sink bookings late

Ask these before shortlisting, not after:

- Noise curfew, and whether it applies to amplified sound specifically
- Kitchen: full, prep-only, or none — this determines which caterers can bid
- Power: available amperage and whether a generator is needed for AV
- Accessibility: step-free entry, accessible restrooms, lift access to all levels
- Parking and transit, especially for evening events
- Outdoor space: is there a weather contingency, and what does tenting cost
- Capacity for simultaneous events — a shared lobby is a real problem

### 4. Rank with honest trade-offs

A shortlist where every option looks equally good is not a shortlist. For each
venue give the single strongest reason to rule it out. If you cannot name one,
you have not researched it enough.

Recommend one. State the trade-off you are accepting by recommending it.

### 5. Verify before recommending

Check availability for the actual date. Cross-check the listing against recent
reviews for anything the directory would not carry: renovations in progress,
a change of management, repeated complaints about the on-site coordinator.

## Output

Write the full comparison to the file path you were given, structured as one
section per venue plus a ranked recommendation. Return only a short summary —
the orchestrator reads the file when it needs the detail.
